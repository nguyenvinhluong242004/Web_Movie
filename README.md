# 🎬 Movie Streaming Website  
## Personal Project – Web App for Watching Movies

### 📌 Mô tả dự án  
**Movie Streaming Website** là nền tảng xem phim trực tuyến, cho phép người dùng duyệt, tìm kiếm và xem các bộ phim với chất lượng cao. Giao diện thân thiện, dễ sử dụng và hỗ trợ phát video mượt mà trên cả máy tính và thiết bị di động.

---

### 🚀 Tính năng chính
- 🎥 Duyệt và xem phim theo thể loại, tên phim  
- 🔍 Tìm kiếm phim theo tên, thể loại, năm sản xuất  
- 📅 Phân loại phim theo năm, thể loại, độ tuổi  
- ⭐ Đánh giá và bình luận phim - planing
- 👥 Tạo danh sách yêu thích và lịch sử xem phim - planning

---

### 🛠️ Công nghệ sử dụng
- **Frontend:** HTML, CSS, HBS Template  
- **Backend:** Node.js, Express.js  
- **Database:** PostgreSQL  
- **Authentication:** JWT 
- **Deploy:** Render
